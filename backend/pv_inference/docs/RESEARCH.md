# 冻结光伏模型科研说明

发布日期：2026-10-12。此包固定10份已验证joblib模型，不执行任何训练、GridSearchCV、参数搜索或验证集重新选型。

## 数据与输入范围

八份state_grid模型对应原始八站，名义容量依次为50/130/30/130/110/35/30/30 MW；不可以把某一站权重直接当作任意电站通用模型。每站使用64个15分钟观测（相邻点跨度945分钟），历史功率及TSI/DNI/GHI/温度。缺测和跨间隙窗口排除。
SKIPP’D来自斯坦福天空图像/光伏数据，30.1 kW-DC参考容量，America/Los_Angeles时区；skippd使用30分钟功率/太阳特征，skippd_images还需30张64×64 RGB图或等价的26维描述。预测时距15/60/240分钟。源功率前向分钟平均按分钟结束后可用；图像需对应该发布时刻的历史行。太阳位置/晴空值可按未来时间计算，不读取未来实测。
所有历史输入按电站本地日历计算时刻/年周期，滞后与统计窗口固定。功率除以冻结Cap，辐照除以1000，温度除以40；Ridge内部标准化器冻结。训练历史时槽均值存于权重，仅查询、不重算。准确率指1−MAE/Cap或1−RMSE/Cap，不是分类命中率。

## CV与验证协议

已补充独立五折时序CV研究，详见[CV报告](CV_REPORT.md)；这些指标属于每折重拟合流程，原冻结权重保持不变，不能把折模型成绩标为冻结权重本身的CV成绩。本轮原实验是按有观测记录的本地日期60/10/30时序留出，并过滤跨分区历史和目标。验证前60%的日期调优/选型，后40%日期残差校准。具体边界、样本数、数据源SHA256及时间可用性假设见manifest.models。

## 模型与局限

冻结集成包括已拟合Ridge、HistGradientBoosting、ExtraTrees及多种LightGBM，非负权重和为1，按时距在验证集选定。joblib中可能含历史训练参数作为元数据，但包内没有训练入口。概率输出是验证后段残差分位数加到点值并裁剪，P50与点值分开，不保证条件覆盖。
- 天空轻量图像特征在本次测试表现弱于无图像集成，保留它用于既有验证方案，不能宣称图像总能提升。没有完成SUNSET/VMamba/FusionSF等全套训练复现。
- 缺少真实发布批次NWP、站点可用AC容量以及部分地理信息；国家电网未来气象不输入。这限制1小时和4小时的效果。
- SKIPP’D只有白天数据；国家电网全时段含夜间低功率，白天06:00–19:00代理指标较低，原白天指标附在manifest.test_metrics.daylight。
- 天气标签大量unknown，来源cloudy无法可靠分为多云/阴天；不声称三类天气全面验证。异常/限电/设备停机、跨站迁移和季节漂移需要独立监测。
- 名义容量非赛事或实际可用容量，96%达标口径须进一步确认。原气象时间可用性按测量时刻可用假设；实际迟到数据必须拒绝。
- 本包只提供加载/推理模块，未自动注册后端API或切换线上预测服务。生产接入需验证输入字段、延迟、单位、时区和部署环境。
