# 前端交互与可视化规范

## 1. 页面结构

### 站点总览

展示站点名称、当前 SOC、今日收益、今日购电量、当前储能动作和明日计划摘要。

### 曲线分析

展示 24 小时、72 小时或月度曲线。支持时间范围切换、Tooltip、图例开关和数据缩放。

### 方案分析

展示推荐容量、PCS 功率、投资、收益、回本周期、IRR、NPV 和敏感性分析。

### 数据管理

展示站点配置、电价模板、上传记录和数据质量提示。

## 2. 主图规范

### 电价

- 使用阶梯线：ECharts `step: end`。
- 档位使用背景色块：尖峰深红、高峰橙色、平段灰色、低谷绿色。
- Tooltip 显示档位、到户电价和电能量价格。

### 功率

- 光伏使用面积图。
- 负荷使用折线图。
- 净负荷使用虚线。
- 正值和负值区域要能区分自发自用、购电和余电。

### 储能

- 充电使用正值柱状带，蓝色。
- 放电使用负值柱状带或明确的负方向，绿色。
- SOC 使用细虚线，单位为百分比。

## 3. 交互规则

- 所有功率、电量、电价和 SOC 显示单位。
- 数据缺失时显示“无数据”，不显示为 0。
- 预测数据必须区分点预测和区间。
- 规则策略、LP 策略和失败状态要有明显标识。
- 页面必须显示数据时间范围和更新时间。

## 4. 方案页说明

方案页不得只显示一个回本周期，还必须展示：

- 计算假设
- tariff source
- 电价和负荷情景
- 价差敏感性
- 循环寿命敏感性
- 预测或数据质量限制

## 5. MVP 页面验收

- 使用示例数据可以打开总览页。
- 可以切换 24 小时和 72 小时。
- 电价档位和储能动作时间点一致。
- 曲线 Tooltip 的时间和数值来自 API，而不是前端重新计算。
- 没有数据时显示明确空状态。
