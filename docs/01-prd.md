# 产品需求文档（PRD）

## 1. 文档信息

| 项目 | 内容 |
|---|---|
| 产品名称 | 光储一体 · 储能配置优化系统 |
| 文档版本 | v0.1 |
| 当前状态 | 从 0 开始建设，产品初稿 |
| 目标用户 | 工商业用能企业、能源经理、运维人员、方案决策者 |
| 首版目标 | 跑通单站点“数据 → 调度 → 曲线 → 基础收益”的闭环 |

## 2. 背景与问题

工商业用户通常同时面对光伏出力波动、负荷变化、峰谷电价和需量电费。当前方案设计容易出现以下问题：

- 光伏、负荷和电价数据分散，难以统一比较。
- 储能容量往往凭经验选择，缺少可解释的收益依据。
- “规划能赚多少”和“每天怎样运行”使用不同口径，结果不一致。
- 预测结果只给点值，不说明不确定性和适用口径。
- 电价、SOC、功率和单位定义不统一，容易产生业务错误。

## 3. 产品愿景

让工商业用户能够用一套可解释、可复现的工具回答三个问题：

1. 我应该配置多大储能？
2. 每天什么时间充电、什么时间放电？
3. 在不同电价、负荷和预测情景下，投资是否值得？

## 4. 产品目标

### 4.1 首版目标

- 支持单站点配置和查询。
- 支持光伏、负荷、SOC 等时间序列上传或示例数据生成。
- 支持峰谷分时电价模板。
- 支持 15 分钟粒度的规则式日调度。
- 返回完整调度曲线和 SOC 轨迹。
- 前端能展示电价、光伏、负荷、净负荷和储能动作。
- 为后续预测、LP 优化、容量配置保留稳定接口。

### 4.2 后续目标

- 接入气象数据并形成光伏预测。
- 接入负荷预测和现货电价 Provider。
- 实现线性规划调度。
- 实现容量规划、生命周期收益和敏感性分析。
- 支持报告导出和多站点比较。

## 5. 非目标

首版不承担以下职责：

- 储能系统电气设计、消防设计和安全认证。
- 现场设备的实时闭环控制。
- 代替用户进行电力交易申报。
- 直接做生产环境的自动化决策下发。
- 在没有可靠数据的情况下声称模型达到某个预测精度。

## 6. 用户角色

### 6.1 企业决策者

关注投资金额、年收益、回本周期、IRR、NPV 和风险情景。需要快速理解方案是否值得投资。

### 6.2 能源经理/运维人员

关注明日价格、光伏和负荷曲线、储能动作、SOC 和异常数据。需要查看并解释调度计划。

### 6.3 方案或售前人员

关注不同储能配置的对比、假设条件和 PDF 报告。需要以统一口径向客户展示方案。

### 6.4 系统集成方

关注测量数据上传、计划获取、时间戳、单位和错误处理。需要可预测、可复用的 API 契约。

## 7. 典型用户场景

### 场景 A：新站点配置评估

用户录入站点、光伏、负荷、电价和投资假设，系统计算多组容量方案并输出推荐配置。

### 场景 B：明日调度查看

系统读取次日预测和电价，生成 15 分钟粒度的充放电计划，用户查看预期收益和 SOC 变化。

### 场景 C：收益风险比较

用户调整价差、设备价格、循环寿命或负荷情景，系统展示收益和回本周期变化。

### 场景 D：数据质量排查

用户上传历史数据后，系统提示时间缺失、单位异常、重复点和超范围值，不把异常数据静默当成正常数据。

## 8. 功能需求

### FR-001 站点管理

用户可以创建、查看和修改站点基础信息，包括位置、时区、光伏、负荷、电价和储能参数。

### FR-002 数据上传

用户可以上传 `pv_power`、`load_power`、`storage_soc`、`grid_power` 四类时间序列。系统必须校验单位、时间戳、粒度和数值范围。

### FR-003 电价管理

运营人员可以维护峰、平、谷、尖峰时段和价格。电价 Provider 必须向下游返回统一 `PricePoint`。

### FR-004 天气数据

系统根据站点经纬度拉取天气数据。首版允许使用模拟天气数据，天气适配器不能耦合到优化器。

### FR-005 统一预测入口

系统提供统一预测接口，支持光伏、负荷和价格三个目标。分时电价直接读取政策模板，不包装成虚假的预测模型。

### FR-006 日调度

系统根据电价、光伏、负荷、储能容量、PCS 功率、SOC 上下限和禁止反送电配置，生成日调度计划。

### FR-007 容量配置

系统评估不同功率和容量组合，输出推荐方案、收益、回本周期、NPV、IRR、敏感性和计算假设。

### FR-008 曲线展示

系统必须同步展示电价、光伏、负荷、净负荷、储能动作和 SOC，并支持 24 小时与 72 小时查看。

### FR-009 报告导出

系统生成包含配置、曲线、收益、假设和风险说明的 PDF 报告。报告任务应可查询状态。

## 9. 非功能需求

| 类别 | 首版要求 |
|---|---|
| 可解释性 | 返回策略、约束、假设和基准收益 |
| 可复现性 | 相同输入和版本应得到相同结果 |
| 时间一致性 | 所有时间戳带时区，默认站点时区为 Asia/Shanghai |
| 数据安全 | 不在日志中输出密钥和敏感原始数据 |
| 可测试性 | 领域计算不依赖 HTTP 和数据库即可单测 |
| 可扩展性 | 电价、天气、预测和优化算法使用适配器/Provider |
| 运行方式 | 单机 Docker 可启动 |

## 10. 产品指标

### MVP 指标

- 新环境启动成功率：100%。
- 示例站点完整链路成功率：100%。
- 调度结果满足所有硬约束：100%。
- 调度接口返回完整 15 分钟序列。
- 前端曲线与 API 数据一致。

### 后续指标

- 光伏预测误差及其口径。
- 负荷预测误差及其口径。
- 计划执行偏差。
- 方案计算耗时。
- 报告生成成功率。

## 11. 产品风险

- 电价政策和输配电价口径变化会直接影响收益。
- 没有至少一个月历史实测数据时，预测只能使用物理或基线模型。
- 需量电费按月最大需量计算，不能只根据单日调度估算。
- 预测不确定性若不进入调度约束，`p10/p90` 只是展示字段。
- 单纯用固定示例数据得到的回本周期不能代表真实商业承诺。
