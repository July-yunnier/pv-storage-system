# 用户故事与验收标准

## 1. 站点和数据

### US-001 创建站点

作为能源经理，我希望创建一个包含位置、光伏、负荷和储能参数的站点，以便系统对该站点进行分析。

验收：

- 必填字段缺失时返回明确错误。
- 经纬度、时区和单位被保存。
- 站点 ID 唯一。
- 返回的站点对象符合 API 契约。

### US-002 上传测量数据

作为能源经理，我希望上传光伏和负荷时间序列，以便系统生成调度输入。

验收：

- 支持四类约定的数据类型。
- 时间戳必须包含时区。
- 重复点和缺失点有明确处理结果。
- 异常值不会被静默当成正常值。

## 2. 电价和预测

### US-003 维护 TOU 电价

作为运营人员，我希望配置峰谷时段和价格，以便系统计算每日购电成本。

验收：

- 每个时间点只能匹配一个有效档位。
- 时间段边界规则明确。
- 价格 Provider 返回统一 PricePoint。
- 未配置的时间段返回错误，不自动猜测。

### US-004 获取预测结果

作为能源经理，我希望同时获得光伏、负荷和价格曲线，以便判断明日储能动作。

验收：

- 支持多个 targets。
- 预测结果带模型名和版本。
- 有不确定性时返回 p10/p90。
- TOU 价格注明“政策给定，无需预测”。

## 3. 调度和配置

### US-005 生成日调度

作为能源经理，我希望系统生成次日充放电计划，以便减少峰段购电成本。

验收：

- 返回完整时间序列。
- SOC 始终处于配置区间。
- 充放电功率不超过 PCS 限制。
- 禁止反送电配置生效。
- 返回约束列表和预期收益。

### US-006 比较储能配置

作为决策者，我希望比较不同储能容量和功率，以便选择更适合投资的方案。

验收：

- 输出容量、功率、时长和效率。
- 输出 CAPEX、OPEX、年收益、回本周期、IRR 和 NPV。
- 输出敏感性分析。
- 所有结果附带计算假设。

## 4. 展示和报告

### US-007 查看曲线

作为运维人员，我希望在同一时间轴上查看电价、光伏、负荷、净负荷、储能动作和 SOC。

验收：

- 电价是阶梯图。
- 峰谷档位有背景色块。
- 光伏、负荷、净负荷和 SOC 可区分。
- Tooltip 显示时间、数值和单位。

### US-008 导出报告

作为售前人员，我希望导出包含方案和假设的报告，以便交付给客户。

验收：

- 报告包含输入、输出、假设和限制。
- 生成过程有状态。
- 失败时可定位原因。
