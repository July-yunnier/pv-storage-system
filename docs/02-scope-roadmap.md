# 范围与路线图

## 1. 当前状态

当前没有系统代码、数据库、接口服务或前端页面，只有一份 v0.1 系统设计稿。因此本项目采用“先闭环、后增强”的策略。

## 2. MVP 范围

### 包含

- 单站点
- 站点配置
- TOU 电价
- 15 分钟时间粒度
- CSV/JSON/模拟时间序列
- 规则式 Dispatch
- SOC 状态计算
- 基础 API
- ECharts 曲线看板
- SQLite
- Docker 本地启动

### 不包含

- 现货电价真实接入
- 机器学习预测训练平台
- 多站点集团模型
- 生产 EMS 下发
- 复杂权限、计费和租户体系
- 复杂电气约束和消防设计

## 3. 阶段路线图

| 阶段 | 目标 | 主要交付 |
|---|---|---|
| P0 | 工程骨架和契约 | 仓库、启动方式、数据模型、API 约定 |
| P1 | 数据和 Provider | 站点、测量、电价、模拟天气 |
| P2 | Dispatch 闭环 | 规则调度、SOC、约束校验和测试 |
| P3 | 前端看板 | 总览页、曲线页、调度结果展示 |
| P4 | Forecast 基线 | 光伏/负荷基线预测和统一结果格式 |
| P5 | Sizing 与经济性 | 容量扫描、收益、NPV、IRR、敏感性 |
| P6 | 报告和交付 | PDF、演示数据、部署说明、验收 |

## 4. 版本定义

### v0.1：可演示闭环

固定示例站点 + TOU + 模拟/CSV 数据 + 规则 Dispatch + 前端曲线。

### v0.2：可配置分析工具

增加天气数据、预测基线、Sizing、收益测算和报告导出。

### v0.3：优化增强

增加 LP、需量控制、预测不确定性和更多 Provider。

### v1.0：可试点系统

增加权限、审计、可靠数据接入、任务队列、部署监控和真实用户试点。

## 5. 版本退出条件

每一阶段必须同时满足：

- 代码或文档交付物存在。
- 有自动化测试或可重复验收步骤。
- 输入输出契约已更新。
- 已知限制写入决策记录。
- 可以由另一位开发者独立运行或复核。
