# 光伏预测与数据源演进路线（讨论纪要 + 开发顺序）

> 状态：已确认方向，待逐项实施。本文记录 2026-09 技术讨论结论，作为 I7+ 迭代的依据。

## 1. 现状与不足（诚实评估）

当前光伏预测链路：**历史同刻均值（纯统计）**，无气象输入、无物理模型。

- 移植的自兄弟项目的"超短期统计法"只采用了日前场景可用的部分（同刻均值），其验证指标（0.9506）对应的是第 4 小时预见期 + 偏差延续，**不能为当前实现背书**。
- "同刻均值"本质是气候态基线：回答"典型的一天"，无法预知"明天阴天"。
- 种子仿真数据为"正弦波+噪声"玩具级，自评精度存在循环论证。
- p10/p90 由全天混合残差生成，正午不确定性被低估；不确定性未进入调度约束（PRD 风险项 #4 成立）。
- 冷启动死区：少于 3 天历史无法出预测。
- 调度把点预测当确定事实，未做保守情景。

## 2. 数据源分层（方向确认）

按"信息质量 × 获取成本"分四层，逐层增强、可插拔：

| 层 | 来源 | 定位 | 现实约束 |
|---|---|---|---|
| 实测功率 | 逆变器/电表/EMS | 金标准（ground truth），预测的训练与校准源 | 有削顶/限电/时钟漂移/断档，需质量清洗 |
| 卫星辐射产品 | Solcast / Open-Meteo Satellite Radiation API | 成品 GHI/DNI/DHI，短临与实况 | 不自建云图反演（见 §4） |
| 数值气象预报 | Open-Meteo（GHI/DNI/DHI 逐小时，≤16 天） | 日前预测、冷启动 | 免费层非商用、1 万次/天 |
| 天空相机 | SUNSET（兄弟项目成果） | 15-30 分钟短临 | 企业站点无相机，**明确放弃** |

## 3. 开发顺序（已确认）

1. **Open-Meteo Provider**：站点经纬度 → 逐小时 GHI/DNI/DHI 预报（日前 + 冷启动）
2. **pvlib 转换链**：GHI/DNI/DHI → 组件面辐射（POA，Hay-Davies 转置）→ 功率（装机 × (1−系统损耗)），物理转换不自研，使用 pvlib
3. **统计法残差修正**：站点积累实测后，用实测偏差校准辐射模型输出（两层融合）
4. **日内滚动修正**：启用 alpha 偏差延续，用当日已发生实测修正当日剩余时段（兄弟项目算法的正确位置）
5. **仿真层升级**：L1 pvlib 晴空模型 + 云况情景（替换正弦玩具）/ L2 实测回放 / L3 辐射驱动；Sizing 年化从"典型日×365"升级为 TMY 8760 逐时（后续）

明确不做：
- 自己分析卫星云图（FY-4A 等）：原始数据为 HDF 图像、免费渠道仅最近 24h、反演为专业团队级工程量；消费成品辐射产品即可
- 自造仿真标准框架：站在 pvlib / NREL PVWatts / TMY 生态之上

## 4. 关键事实备忘

- FY-4A 云图：覆盖中国区，VIS/IR/WV 三通道，4km、每小时；国家卫星气象中心实名注册下载（HDF 原始数据）；第三方 API 仅近 24h 图像
- Open-Meteo：免费非商用、10k 次/天、逐小时最长 16 天；另有 Satellite Radiation API（多卫星反演辐射成品）
- 预测口径纪律（沿用兄弟项目原则）：任何精度数字必须带 caliber（归一化基准/是否含夜间/空间尺度/对照基线）；TOU 电价不包装成预测
