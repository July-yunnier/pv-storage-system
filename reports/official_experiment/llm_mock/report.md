# E_LLM 独立扩展实验（mock_offline）

本轮新增受约束的策略顾问实验臂，不替代原P0–P4，也不改变P0-A结论。顾问固定返回15%保留SOC、零偏移，作为接口、安全与封存机制验证。**未调用真实LLM服务，不能宣称LLM推理带来经济收益。**

## 方法

P0使用2019-04-01至2019-04-30共30天，E_LLM与E0/E1/E2/E3使用相同实际PV/负荷、电价、500kW/1000kWh储能和效率。E_LLM发报输入仅含历史生成预测、已知政策价格及历史摘要，SOC连续继承。每次策略参数和输入在执行实际结算前写入归档。执行函数保持原样；预测侧保留SOC参数不改变10%–95%的物理边界。

`peak_discharge_offset`为15分钟槽偏移，允许−4至4，正值延后放电；不循环跨日。参数由有限数检查及裁剪保护；API/解析错误使用10%保留SOC与零偏移，记录fallback状态。

## 结果

| 阶段 | E_LLM结果 | 与对照差异 | 结论边界 |
|---|---:|---|---|
| P0 | 电费202,842.43元；比E0节省12,591.87元 | 比E2多花5,920.18元 | mock策略比E2更差，不能称LLM收益提升 |
| P1 | 含需量总成本234,869.11元；比E0节省8,565.19元 | 需量单价假设35元/kW·月 | 复用P0计划做结算，非需量优化 |
| P2 | 90天E_LLM与E2费用相同 | 日差CI [0,0] | PJM演示；TOU阈值在价格尺度下可能不触发放电，不能称有效 |
| P3 | 同P0窗口 | 比预测LP多花6,275.50元 | 同预测执行经济比较 |
| P4 | 合成年节省140,788.87元 | 同批次E2为224,209.56元 | 独立365天合成批次，不与旧年度总额混算 |

P0 E_LLM相对E2日节省差均值−197.34元，按日配对bootstrap 95% CI [−296.99,−101.94]元；相对E1日差−234.93元，CI [−307.36,−166.44]元。仅解释此固定mock策略、此数据窗口，不代表真实LLM表现或广东现场收益。

P0、P2、P4执行SOC违规均为0，P1/P3复用同一安全执行结果。顾问调用485次，fallback 0次。金额单价元/kWh，需量单价单独按元/kW·月；所有发报/目标时间戳均带时区。

P4使用30天暖启动、365天过去信息预测和连续SOC，衰减沿用2%/年示例；该批次与旧P4含冷启动/实测负荷近似的结果独立保存。循环重用90天来源数据会引入相关性，年度bootstrap CI只作描述，不构成真实年度收益或投资验收。

## 复现

```bash
cd backend
python scripts/run_official_experiment.py --agent llm --mock-offline
# 调用配置的OpenAI兼容API（本轮未执行）：
python scripts/run_official_experiment.py --agent llm --no-mock-offline
```

配置见 `backend/.env.example`，运行时由python-dotenv加载`backend/.env`，进程环境变量优先。默认Ollama配置仅用于本地开发；mock不创建网络客户端。

产物：`p0_replay/summary.json`包括E_LLM汇总和P0–P4索引；各阶段保存CSV/JSON；`agent_policy_archive.jsonl`封存预测输入、历史摘要、参数和fallback；`run_meta.json`记录输入/脚本/归档哈希及模式。模型参数不可变更执行器物理边界，生产API未扩展。
