# 真实本地 LLM：P0 30 天试运行

模型：qwen2.5:7b，提示词版本 local-pilot-v1，评估窗口 2019-04-01 至 2019-04-30（Asia/Shanghai）。本轮在独立副本运行，未修改原 PR。

## 方法

真实调用本机 Ollama 的 OpenAI 兼容 API，温度 0，每日调用一次；只输入既有历史生成预测、已知政策电价、历史摘要和该臂继承 SOC。提示词冻结后未按收益调参。所有 96 槽预测保留，小数压缩为三位、规则时间网格编码为起止时间与分辨率。输入、输出和降级状态在结算前封存。电池参数与费用目标写入提示词；SOC 硬边界仍由原 execute 保证。

接口预检曾因冷启动超时、字段缺失失败；这些预检不计入正式 30 天批次。预检仅用于接口兼容，正式批次使用修订提示词，不能与原提示词混为一轮。

## 解读与边界

是否省钱需看配对差与置信区间。E2 与新规划器存在计划功率计算差异，直接比较不能把全部差额归因于 LLM；同规划器固定 10%/15%/50% 对照用于分离这一混杂因素。CI 使用按日配对 bootstrap，2000 次、seed=42，连续 SOC 会带来日间相关性，因此本次 CI 仅作试运行描述，不作为现场收益承诺。

本轮仅完成 P0 真实 LLM 试验，P1–P4 尚未运行真实模型；P0 数据仍为公开光伏代理、仿真负荷、政策价格演示场景。无真实广东现场收益或投资回报结论。温度 0 不保证跨硬件与服务版本严格确定，归档可复核本次策略。
