- `publication_manifest.json`：本次发布的所有以上文件的 SHA256；不包含清单自身。原实验时间、commit 和哈希仍表示原始执行状态。

## 主要结果与边界

模型 qwen2.5:7b、local-pilot-v1；P0 窗口 2019-04-01 至 2019-04-30（Asia/Shanghai）。真实模型成功调用 30/30，降级与 SOC 违规均为 0；电费 206,479.28 元，相对 E0 节省 8,955.03 元，但比 E2 多花 9,557.02 元。

P1/P3 是复用这 30 次封存策略的离线结算和事后诊断，新增模型调用 0 次；不代表完成 P2/P4 真实 LLM 运行。P1 含需量账单比 E2 多花 9,403.02 元，P3 电量费比预测 LP 多花 9,912.34 元。原诊断记录的 390 passed 属于侧边工作区的验证，相关新增测试收录于源码快照。

数据为公开光伏代理、仿真负荷和政策价格演示场景。各臂规划器差异、终端 SOC、连续 SOC 的日间相关性与事后分析等限制详见报告；不宣称真实广东现场收益、LLM 优于现有调度或降低事故概率。

## 离线复核

先按 `publication_manifest.json` 核验文件。P1/P3 可使用源码快照中的 `analyze_llm_live_p1_p3.py` 在一次性工作区复核，不需要模型服务；命令及“输出目录必须尚不存在”的要求见正式诊断报告。原目录已有封存结果，应将根目录封存输入复制到新运行目录，不复制已有的 `p1_p3_diagnosis/` 子目录，再把 `--run-dir` 指向新运行目录。

重新执行 P0 会调用已配置的模型服务并形成新批次，不能覆盖本轮归档或视作逐位复现。服务配置仍使用环境变量和本地 `.env`；本归档不含 `.env`、API 密钥或模型权重。
